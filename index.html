01 // INFRASTRUCTURE AS CODE

AWS Infrastructure Automation with Terraform

Automated provisioning of complete AWS environments from scratch using Terraform HCL.

  • Provisioned VPCs, subnets, security groups, EC2, ASG, ELB, and S3
  • Managed AMIs and Launch Templates for repeatable deployments
  • Used variables, outputs, and locals for reusability
  • Practiced full plan / apply / destroy cycle with remote state
02 // CI/CD

Jenkins CI/CD Pipeline

End-to-end Jenkins pipeline integrated with GitHub to automate build, test, and deploy.

  • Pipeline: checkout → build → test → Docker build → push → deploy
  • GitHub webhook triggers builds on every push to main
  • Credentials stored in Jenkins — no hardcoded secrets
  • Images tagged with build number for traceability
03 // KUBERNETES

Kubernetes Cluster Management

Deployed containerized applications on Kubernetes with full manifest management.

  • Deployment, Service, StatefulSet, and Ingress manifests
  • Namespaces and ReplicaSets for workload isolation
  • Rolling updates and replica scaling with kubectl
  • DaemonSets for cluster-wide daemon processes
04 // GITOPS / CI/CD

End-to-End CI/CD with Jenkins + ArgoCD + AWS EC2

Fully automated GitOps pipeline — every push triggers a complete build-and-deploy cycle with zero manual steps.

  • Jenkins polls GitHub every minute — commits trigger the pipeline
  • Jenkins builds the Docker image on EC2 and pushes to Docker Hub
  • Jenkins updates the image tag in deployment.yaml via sed
  • ArgoCD watches the config repo and auto-deploys with self-heal
