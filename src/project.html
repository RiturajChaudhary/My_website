    Delivery steps

    1. Developer creates a feature branch and opens a pull request.
    2. CI checks out the code, installs dependencies, runs unit tests, SonarQube analysis, and OWASP Dependency-Check.
    3. The application is built, packaged into a Docker image, scanned with Trivy, and pushed to a container registry.
    4. The update repository receives the image update and Argo CD synchronizes it to DEV.
    5. Integration tests run before the release is deployed to STAGING and then PRODUCTION.
    6. Prometheus collects operational metrics and Grafana provides dashboards for production monitoring.
